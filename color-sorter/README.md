A progressive EV3 Tank Bot series designed for children learning programming concepts through experiments.

**Hardware:** LEGO EV3 Tank Bot built as the color sorter per instructions from LEGO. Additionally an ultrasonic sensor is mounted near the color sensor. 

| Lesson | Goal | Key idea |
|---|---|---|
| [1. Sort color one at a time](lesson-01-sort-one-at-a-time) | Modified sorter with ultrasonic port 2 and human loading| loops, object detection, color identification, distance calibration|

### Reference solutions

**Safety:** Use a clear floor area, low speeds, and adult supervision. The ultrasonic sensor is not a failsafe collision-avoidance system. Lesson 8's first strategy may get stuck in a maze.
